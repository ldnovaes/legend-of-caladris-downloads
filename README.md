# Legend of Caladris — downloads oficiais

Este repositório só guarda os arquivos para baixar o jogo. Não tem código.

- **Android (APK):** veja a [última versão](https://github.com/ldnovaes/legend-of-caladris-downloads/releases/latest).
- **Jogar no navegador:** https://legend.eldialabs.com/jogar/
- **Site oficial:** https://legend.eldialabs.com/

## Como instalar no Android

1. Baixe o arquivo `.apk` da última versão.
2. Confira, se quiser, o código SHA-256 que está na descrição da versão.
3. Abra o arquivo no celular e permita "instalar de fontes desconhecidas" quando o Android pedir.

Baixe só por este endereço ou pelo site oficial. Versões de outros lugares podem ser falsas.
